# Validation scope

The source packaging pass verified 59 pinned reference files and 30 lobby
regression cases in a fresh Git checkout. Required project fonts are tracked and
protected against line-ending changes and missing inputs.

Prior integration evidence records Standard/EZ4 ROM compilation and Standard
mGBA character creation, dungeon entry, 128KB save/reload and floor 5/16 loads.
These emulator tests were not rerun during publication.

Independent unattended clean generation, GOG MPQ, physical GBA/EZ4/link cable
and standalone Windows/macOS converter tests remain open.

Detailed internal generation/release comparison reports are omitted from this
public repository. Build input maps, integrity manifests and source provenance
records needed by the tools are included. No game assets or ROMs are bundled.
